Criar conta de administrador

O que dá permissão de alterar o site é um token do GitHub (só do repositório do HubPG). Ao criar a conta, o token fica guardado criptografado neste navegador, protegido pela senha que você escolher, e nas próximas vezes você entra só com a senha. A senha pode ser curta, mas senha curta é fácil de adivinhar por quem usar este aparelho. A conta vale só neste aparelho: em outro, crie de novo com o token. Quem não tem a senha nem o token abre esta página, mas não consegue alterar nada.

Entrar com uma conta do Google não é possível neste tipo de site, porque isso exige um servidor.
